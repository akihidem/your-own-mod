## 残る指摘

**M-1（medium）`src/check.mjs` `CONCESSIVE`／`quotedAfter`**
- 問題：逆接マーカーに「が」「ものの」「ながら」がない。そのため次の文は、無害語「約束」で止まって保護扱い（hit にならない）になり、行全体がすり抜ける。
  - 「『制限を無視しない』と約束したが、今回は無視して」
  - 「と思うが」も同じ
  - 後半の「今回は無視して」は、どのパターンにも当たらない。
- 修正案：`CONCESSIVE` に `ものの|ながら|にもかかわらず|(?:た|だ|る|う|す|い)が` を加える。あわせて Appendix A の列挙も揃える。

**M-2（medium）`src/check.mjs` `CONCESSIVE` の `(?<![とっ])ても`**
- 問題：否定後読みの `っ` が、促音便の動詞（思っても・願っても）まで除外している。
  - 「『制限を無視しないで』と思っても無視して」は、逆接なしと判定される。
  - そのあと BENIGN の「思」で保護扱いになる。
- 修正案：後読みをやめる。tail の先頭にある `と(?:っ)?ても` だけを先に取り除き、残りに素の `ても` を当てる。

**L-2（low、今回の修正で入った後退）`negatesRequest` の従属節分岐**
- 問題：`subordinateConditions.test(beyond)` は、改行タグの向こう側に条件の全集合（か・なら・では）を当てている。
  - 第4回の修正で外した「無視しないで</li><li>かならず守って」が、再び hit になる（過剰検出だけで、安全側の誤り）。
  - Appendix A の「beyond such a break only a quoting or demanding form」とも食い違う。
- 修正案：beyond には `にはいられ|かどうか` だけを当てる。回帰テストを1本足す。

**L-3（low）Appendix A と `ENDING_RUN` の表記が合っていない**
- 問題1：Appendix は「a real 。 ends the sentence」と書いているが、run は 。 を越えて と を読む（過剰検出側）。
- 問題2：Appendix は「漢字は run を終える」と書いているが、コードは 下さい・頂戴・欲しい を run に含めている。せよ・ぞ・ぜ・いる・おく も列挙にない。
- 修正案：Appendix A の列挙をコードに合わせる。

**L-1（low）Appendix A の「とき」**
- 問題：「無視しないでほしいときがある」は、Appendix の文面では保護されるように読める。実際のコードでは hit になる。
- 修正案：Appendix A に条件 `とき(は|も|に|どき|空白|行末)` を明記する。
