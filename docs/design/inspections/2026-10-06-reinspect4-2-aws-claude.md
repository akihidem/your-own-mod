## 2. 残っている指摘

### H-1（high）丁寧形・連用形の否定がまだすり抜ける

- **場所:** quiet-confirmations のトリガー先読みと unless
- **問題:** 否定の形が「〜ない」の終止形しか書かれていません。そのため次の文がトリガーに当たり、unless にも当たりません。
  - 「念のための確認は不要ではありません」
  - 「確認を不要ではなく必須とする」（`ではなく` は `ではない` に一致しません）
  - 「やめてほしくありません」
  - 「控えるべきではありません」
  - 「〜わけではありません」

  どれも「確認は必要だ」とはっきり言っている文に、確認を減らすレシピが提案されます。手引きでは丁寧形が普通なので、珍しい書き方ではありません。
- **修正案:** 否定語尾を共通の部品にまとめます。`な(?:い|く|かった)|ありません(?!か)` を `(?:では|じゃ)`、`て(?:ほしく|もらいたく)`、`るべき(?:では|じゃ)`、`わけ(?:では|じゃ)` の後ろに付けます。同じ部品をトリガー先読みと unless の両方で使います。テストには上の5文を足します。

### M-1（medium）字数の後ろに「で」「に」が続くと件名の規則が拾われる

- **場所:** `JA_NO_OBJECT_AFTER` を使う `JA_CHAR_TRIGGER`
- **問題:** 字数の後ろの対象語は `の` でつながる形しか見なくなりました。返答語を必要としない裸のトリガーでは、次のような文が短答の依頼として誤検出されます。
  - 「50字以内でコミット件名を付ける」
  - 「72字以内に収まる件名」

  M1 以前はこれらを弾けていました。
- **修正案:** 「の」に限る先読みは返答語を持つ `JA_CHAR_LIMIT` だけで使います。`JA_CHAR_TRIGGER` は元の広い先読みに戻し、`\n` とカンマの除外だけ加えます（`(?![^。！？、，,;；\n]{0,16}OBJECT)`）。

### M-2（medium）without の先読みの me/my/review が広すぎる

- **場所:** publish の "without" パターンの先読み
- **問題:** 単独の `me|my|review\w*` があるため、次の文が門（承認の確認）を求める文として扱われます。
  - "never push without running my tests"
  - "without reviewing the diff yourself"

  2回目の再検品で直した L-f が戻っています。両側パターンでも `ask\w*` が "asked" に当たり、"When asked, never push…" が発火します。
- **修正案:** me と my は、承認を表す語と隣り合う時だけ認めます（`(?:let(?:ting)? me|my) (?:review|ok|approval|go-ahead|sign-?off|consent)`）。`review\w*` は `me` の後ろに限ります。両側パターンは `ask(?:ing)?` に戻します。

### M-3（medium）typo の unless の外側に否定が足りない

- **場所:** typo レシピの unless（英語）
- **問題:** 外側の否定の後読みに `don't ever`、`never ever`、`don't need to`、`needn't` がありません。そのため "Don't ever fix my typos" や "You don't need to correct my typos" で unless が発火します。はっきり求められているレシピが消えます。
- **修正案:** 内側の後読みと同じ否定の一覧を外側にも入れます。2箇所で同じ一覧を使ってください。

### L-1（low）unless の「不要ではない」が節に縛られていない

- **場所:** quiet-confirmations の ja unless
- **問題:** `|不要(?:では|じゃ)ない` が最上位の選択肢になっていて、確認の話かどうかを見ていません。「テストは不要ではない」だけで確認のレシピが消えます。安全側に倒れる誤りですが、意図より広いです。また、トリガーにある `ては(?:いけ|だめ)`、`るべき…`、`わけ…` が unless にはありません。トリガー語が2つある文では、片方がすり抜けます。
- **修正案:** 確認語を前に置く選択肢に入れて節に縛ります。否定の一覧はトリガーと同じものにします。

### L-2（low）「トークンの入力」を拾わなくなった
