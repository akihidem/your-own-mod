## 指摘

### 高
1. **index.mjs `JA_VERB_NEGATED`（quiet-confirmations の trigger と unless の両方）**
   - 問題：「は」のない否定と、「は」を挟む否定が抜けています。
     - 「確認の質問はやめるべきでない」：`るべき(?:では|じゃ)` に一致しません。
     - 「確認の質問をやめてほしくはありません」：`て(?:ほしく|もらいたく)` の直後に「は」が入るため一致しません。
     - どちらも普通の書き言葉です。否定の先読みが素通りし、unless も同じ部品を使うので打ち消せません。結果として、反対を求める文にレシピが提案されます。
   - 修正：`るべき(?:では|じゃ|で)`、`(?:では|じゃ|で)${TAIL}`、`て(?:ほしく|もらいたく|いただきたく)は?${TAIL}` を加えます。

2. **publish ゲートの `without` 先読み**
   - 問題：「me」を承認語の直後に限ったため、"Don't push without me reviewing it" と "Never push without a review from me" がゲートを失いました。旧版では裸の `me` と `review\w*` が拾っていたので、これは後退です。
   - 修正：`me (?:review\w*|check\w*|sign\w* off|look\w* at)` と `(?:a )?review from me` を加えます。

3. **publish ゲートの両向き ask パターン（3本目）**
   - 問題：`ask\w*` を `ask(?:ing)?` に狭めたため、"Do not push unless asked" と "Never publish unless the user asks" がゲートを失いました。どちらも AGENTS.md でよく見る普通の文で、他の4本も拾いません。
   - 修正：`ask(?:ing|ed|s)?` に戻したうえで、"When asked" だけを先頭の否定的な先読みで除外します。

### 中
1. **typo の unless、`EN_NOT_BEFORE`**
   - 問題："You don't have to fix my typos" と "You do not need to fix typos" が否定と見なされず、unless が発火します。その結果、本人が求めた「誤字を無視する」レシピが消えます。
   - 修正：一覧に `don['’]t have to`、`do not (?:need|have) to`、`shouldn['’]t`、`never need to` を加えます。
2. **`JA_VERB_NEGATED`**
   - 問題：「ては駄目」（漢字表記）、「ていただきたくない」、「不要だとは思いません」（引用の形の否定）でレシピが発火します。
   - 修正：`ては(?:いけ|だめ|ダメ|駄目)` と、上の「いただきたく」に加え、`不要(?:だ)?とは[^。]{0,6}(?:思|考)(?:わない|いません)` を unless に入れます。
3. **ja の unless（既存の問題で、fold により範囲が広がった）**
   - 問題：「確認の質問はやめて、テストは省かないで」は、読点を越えて「省かない」に一致し、レシピが取り消されます。共有の否定形に「なく」「ではない」が加わったので、この取り消しが起きる範囲が広がりました。
   - 修正：unless の `[^。！？]*` から読点（`、`）を除きます。

### 低
1. **ja の unless**：旧版にあった「省くな」が失われました（`省[きかい]` に「く」がない）。trigger も「省く」を拾わないので、実害は他の動詞と重なる節に限られます。修正は `省(?:[きかい]|く)` です。
2. **`JA_CHAR_TRIGGER` の回答の語がない上限**：「250字以内で答えて件名は不要」は、16 字の窓に件名が入るため簡潔さの依頼を落とします。修正は、窓を述語（「で」に続く動詞）までで止めることです。
